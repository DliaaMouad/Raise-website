# Raise. — Pitch Deck & Investor Readiness

A high-end, conversion-focused landing page and "Get Started" application portal for **Raise.** — helping early-stage founders eliminate deck blind spots, sharpen narrative positioning, and close oversubscribed funding rounds.

---

## 🚀 Live Pages

- **Homepage (`index.html`)**: Long-form landing page with editorial SaaS aesthetic, deck teardown breakdown, founder about section, and interactive audit modal.
- **Get Started Portal (`get-started.html`)**: Focused 900px application portal with deliverables stack, qualification fit matrix, 3-step sprint process, intake form, and interactive FAQ accordion.

---

## 🎨 Design System

- **Background**: Warm off-white / light cream (`#F8F8F4`)
- **Primary Accent**: Neon lime / flash green (`#B9FF66`)
- **Dark Neutral**: Deep carbon black (`#0F1012` / `#111215`)
- **Typography**: Plus Jakarta Sans, Inter, JetBrains Mono
- **Visuals**: Tactile pills, soft elevation shadows, interactive before/after teardowns, smooth accordion toggles, and responsive mobile drawers.

---

## 💻 Local Development

Run any standard local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
